# Khmer Mini Store Website (Pure HTML & CSS)

This project is a recreation of the **Khmer Mini Store (ហាងទំនិញខ្មែរ)** e-commerce store interface based on the reference mockups, built strictly using **HTML5** and **CSS3**.

## 📁 Project Structure

```
Mini_Project/
├── index.html   # Complete semantic HTML5 structure with 16 Khmer products (4x4 grid)
├── style.css    # Modern CSS3 styles, CSS variables, 4x4 Grid layout, and responsive media queries
└── README.md    # Documentation and explanation
```

## 🚀 How to Open and View

1. Double-click [index.html](file:///d:/FRONTEND%20Development/CSS%20Lessons/Mini_Project/index.html) to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).
2. Or in VS Code, right-click `index.html` and click **"Open with Live Server"**.
